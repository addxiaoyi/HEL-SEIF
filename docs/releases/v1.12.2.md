# Helself 1.12.2

本版没有应用功能变化，应用内更新只同步版本号；已有资料沿用原数据目录。

## 升级与发行

Windows 附件为安装包 `Helself-1.12.2-setup.exe`、便携版 `Helself-1.12.2-portable-x64.zip`、浏览器插件 `Helself-1.12.2-browser-extension.zip` 与 `SHA256SUMS.txt`；应用内更新沿用同次构建的 `latest.yml` 和 `.exe.blockmap`。安装包与便携版均未做代码签名，请核对 SHA256。浏览器插件仅同步版本号。

## 验证

- TypeScript、ESLint、i18n 与单元测试通过；打包程序的 19 项发布检查全部通过。
- 已知：`agent-workspace` 的桌面输入区贴底断言（8px 间距）以及 `usage-charts`、`usage-insights`、`relations-usage-ui`、`mail-push`、`probe-desktop` 在 1.10.0 上同样失败，与本版改动无关。
