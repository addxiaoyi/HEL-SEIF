本轮源码、打包程序和一次性 Windows 完整安装验收已通过，尚未创建 1.17.13 GitHub Release。当前产物没有 Authenticode 签名，公开下载和在线安装仍需正式附件发布后验证。

## 本次修复

- 本地文档列表或正文读取失败时停止本轮文档同步，避免把读取错误解释为删除并传播到其他设备。
- 普通文档保存增加 revision 校验；另一端已有修改时返回冲突，保留当前草稿，并提供另存副本入口。
- 粘贴整理忽略过期请求的结果，跨面板保留进行中状态和错误，防止旧响应覆盖新内容或重复提交。
- Windows 安装器写入目标、工作目录、AUMID 与原生 GUID 类型的 Toast 激活身份，避免通知初始化重建快捷方式后丢失图标；开发、便携和显式隔离资料启动不自动注册系统通知。
- 两种用户目录参数形式统一解析并应用到资料和会话目录；无效参数在读取默认资料前失败，协议注册、快捷方式迁移和扩展桥也遵守同一隔离判定。
- 网页保存失败保留内存草稿，支持重试、顺序写入、恢复后续存及多设备冲突处理；本地敏感原文不写入浏览器持久存储。
- 桌面打包将共享 TypeScript 模块编译为 JavaScript，并补全运行依赖；Docker 运行层沿用同一共享模块编译流程，避免镜像构建成功后服务因缺模块退出。
- 统一 PWA、扩展、桌面窗口、原生终端及安装器的品牌图标；修复 Windows 预览进程管理和重复 `--publish never` 参数处理，本地打包继续强制禁止发布。
- 更新日志生成器使用语法树读取单行及多行字符串数组，保留方括号和转义字符；非法输入先报错，导入脚本不再自动写文件。
