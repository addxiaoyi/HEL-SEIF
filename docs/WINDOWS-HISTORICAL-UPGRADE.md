# 从知屿 1.17.3 迁移到 Helself 1.17.13

两版桌面应用共用 Windows 用户资料目录 `%APPDATA%\Nanpad`，但 Windows 安装登记不同。直接运行新版离线安装器会并排安装，旧程序、快捷方式和开机启动仍可能保留。迁移前请先使用旧版「备份与恢复」创建加密备份，并记录旧版安装目录、安装范围和开机启动选项。

1. 退出知屿（含系统托盘）。在 Windows「设置 → 应用 → 已安装的应用」里卸载「Zhiyu 1.17.3」。保留本地资料；不要删除 `%APPDATA%\Nanpad` 或使用清理个人数据的选项。
2. 确认卸载完成，且原目录里的 `Zhiyu.exe` 已移除。若开始菜单或桌面仍有知屿快捷方式，在属性中核对它确实指向刚移除的旧程序，再删除该快捷方式。
3. 用 Helself 安装器选择与旧版相同的安装范围和原安装目录。按原有偏好设置 Windows 开机启动；这是系统设置，旧卸载器会删掉知屿的开机启动项。
4. 用同一 Windows 账户打开 Helself。核对工作区和文档内容，用原主密码解锁密钥库，再确认提醒及通知等应用设置。
